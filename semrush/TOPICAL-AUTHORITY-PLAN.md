# خطة السلطة الموضوعية (Topical Authority Plan) — brightai.site

**الهدف:** أن يعامل Google (وAI Overviews وChatGPT وPerplexity) موقع brightai.site كـ**المرجع الأول في السعودية** لكل ما يتعلق بحوكمة وأمان وامتثال الذكاء الاصطناعي.

**المنطق:** السلطة الموضوعية لا تُبنى بمقالات متفرقة بل بـ**عناقيد كاملة** تغطي الموضوع من كل زواياه، مترابطة داخلياً حول صفحة Pillar واحدة.

## البنية الهرمية للربط الداخلي

```
                    / (الرئيسية: حوكمة الذكاء الاصطناعي)
                            |
        +----------+--------+--------+----------+
        |          |                 |          |
   /solutions   /docs (Pillars)   /blog      /assessment
        |          |                 |
   قطاعات/مدن   6 أدلة شاملة    42+ مقال عنقودي
        |          |                 |
        +----------+--------+--------+
                            |
                  /demo + /pricing (التحويل)
```

**قواعد الربط:**
1. كل مقال يربط: Pillar عنقوده (إلزامي) + مقالين شقيقين + صفحة solution واحدة.
2. نصوص الربط (Anchor Text) تستخدم الصيغة الحرفية للكلمة المستهدفة، مع تنويع 20%.
3. الـPillar يربط بكل مقالات عنقوده (جدول محتويات العنقود في نهاية الصفحة).

## طبقة AEO / GEO (الظهور في محركات الذكاء الاصطناعي)

1. **فقرة التعريف المباشر:** كل صفحة Pillar تبدأ بتعريف 40-50 كلمة قابل للاقتباس الحرفي (هذا ما تقتبسه AI Overviews وPerplexity).
2. **FAQ Schema:** على كل Pillar والصفحات التجارية — الأسئلة من قسم AEO في `KEYWORD-REPORT.md`.
3. **تحديث `public/llms.txt` و`public/llms-full.txt`:** إدراج كلمات الأساس الخمس وروابط الـPillars الستة وصيغ الأسئلة.
4. **جداول وقوائم مرقمة:** المحتوى المهيكل يُقتبس أكثر من السرد — كل دليل يتضمن جدول متطلبات أو checklist.
5. **التواريخ والمصادر:** ذكر أرقام المواد النظامية وتواريخ الإصدار — إشارات E-E-A-T التي ترجحنا على مكاتب المحاماة في سياق الذكاء الاصطناعي.
