<section>
<h2 id="audit-why">ليش تدقيق ECC للذكاء الاصطناعي مهم؟</h2>
<p>تدقيق ضوابط ECC لأنظمة الذكاء الاصطناعي هو الخطوة الأخيرة قبل تقديم النظام للاستخدام. بدون تدقيق، المؤسسة تعمل بمخاطر غير معروفة وقد تفشل في تفتيش NCA.</p>
<p>التدقيق يتحقق من: هل كل ضابط من ECC مطبق على أنظمة AI؟ هل الضوابط تعمل بشكل صحيح؟ هل في فجوات؟</p>
<p>للذكاء الاصطناعي، التدقيق يختلف لأن الأنظمة ديناميكية. النماذج تتغير، API تُحدّث، البيانات تتدفق. التدقيق لازم يغطي كل هذه الأبعاد.</p>
</section>

<section>
<h2 id="audit-checklist">قائمة فحص تدقيق ECC للذكاء الاصطناعي</h2>
<p>قائمة فحص شاملة للمدققين:</p>
<h3>أمن API والنماذج</h3>
<ul>
<li>هل API النماذج محمي بـ API Key؟</li>
<li>هل في Rate Limiting على الطلبات؟</li>
<li>هل في فحص للـ prompt injection؟</li>
<li>هل النماذج محمية من التعديل غير المصرح؟</li>
<li>هل في فصل بين بيئات التطوير والإنتاج؟</li>
</ul>
<h3>حماية البيانات</h3>
<ul>
<li>هل قاعدة بيانات المحادثات مشفرة؟</li>
<li>هل البيانات تُحذف وفق جدول زمني؟</li>
<li>هل في تصنيف للبيانات الحساسة؟</li>
<li>هل الـ embeddings محمية؟</li>
</ul>
<h3>المراقبة والسجلات</h3>
<ul>
<li>هل كل تفاعل مع النماذج مسجل؟</li>
<li>هل في تنبيهات للنشاط غير الطبيعي؟</li>
<li>هل السجلات محمية من التعديل؟</li>
<li>هل في إبلاغ عن الحوادث؟</li>
</ul>
</section>

<section>
<h2 id="audit-process">عملية التدقيق</h2>
<p>عملية التدقيق تمر بـ 5 مراحل:</p>
<p><strong>المرحلة 1 — التخطيط:</strong> حدد نطاق التدقيق. حدد أنظمة AI المراد فحصها. حدد فريق التدقيق.</p>
<p><strong>المرحلة 2 — جمع الأدلة:</strong> احصل على وثائق النظام. راقب التفاعلات. افحص الإعدادات.</p>
<p><strong>المرحلة 3 — التحليل:</strong> قارن الواقع بضوابط ECC. حدد الفجوات. صنّفها حسب الخطر.</p>
<p><strong>المرحلة 4 — التوثيق:</strong> اكتب تقرير تدقيق. حدد الفجوات. اقترح خطوات سد.</p>
<p><strong>المرحلة 5 — المراجعة:</strong> عرض التقرير على الإدارة. اتفق على خطة إصلاح. حدد مواعيد متابعة.</p>
</section>
