---

## تسلسل التجديد (Renewal Cadence)

| التوقيت | الإجراء | المسؤول |
|---|---|---|
| 90 يوم قبل | توقّع التجديد + تحديد المخاطر (Risk Forecast) | CSM |
| 60 يوم قبل | مقترح التجديد + خطة التوسع (Expansion Plan) | CSM + Sales |
| 30 يوم قبل | التفاوض على العقد (Contract Negotiation) | CSM + الراعي |

| 0 يوم | توقيع + احتفال (Celebrate) | CSM |

## قالب مقترح التجديد (Renewal Proposal — عربي)

```
إلى: [الراعي] — [اسم العميل]

الموضوع: مقترح تجديد + توسع — [السنة]

1) القيمة المحققة خلال السنة (Value Delivered):
   - تقليل مخاطر PDPL/NCA: ____% (الهدف 80%+)
   - ساعات موفّرة/شهر: ____ (الهدف 40+)
   - Evidence Files معتمدة: ____
   - اختراقات بيانات: صفر ✅

2) خطة التوسع المقترحة (Expansion):
   - [حجم الطلبات >80% → ترقية باقة] / [أقسام متعددة → add-on packs]
   - [مكتب دولي → multi-region] / [متطلب امتثال جديد → compliance pack]

3) شروط التجديد:
   - الباقة: [Foundation / Business / Enterprise]
   - المدة: [12 شهر]
   - القيمة: [____] ريال
   - التوسع المضاف: [____]

4) الخطوة التالية:
   نثبّت مكالمة تنسيق خلال 14 يوم لإنهاء التوقيع.
```
