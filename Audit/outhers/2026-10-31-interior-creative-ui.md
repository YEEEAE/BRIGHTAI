- ملف `src/styles/interior.css` مستورد في PageShell وKernel فقط. جميع قواعده تخص الصفحات الداخلية؛ لا تغيير لـ`:root` العام أو `experience.css` أو `site.css` أو قالب الرئيسية.

- `DecisionCircuit` و`SectorDiagram`: SVG أصلي متجاوب؛ الرسوم الزخرفية مخفية عن قارئ الشاشة، والمعلومات النصية والمراحل موجودة في HTML.
- `InteriorController`: ظهور محدود للأقسام دون انتظار JS لقراءة المحتوى، انتقال حالة قصيرة، توهج مؤشر على الأجهزة ذات مؤشر دقيق فقط، تقدم قراءة، وفهرس أقسام اختياري مع تركيز لوحة مفاتيح. لا تقسيم لحروف العربية أو إخفاء H1.
- فهرس الأقسام يختفي عند ظهور الفوتر، ويعزل عداده اللاتيني عن RTL. الربط بالعناوين ينقل التركيز إليها؛ التنقل عبر وثائق المتصفح والرجوع لا يكرر عناصر الفهرس أو التقدم.
- تنظيف observers وrequestAnimationFrame عند pagehide وإعادة تهيئة مناسبة عند الرجوع من BFCache. لا حلقة رسم مستمرة أو scroll hijacking أو ClientRouter جديد؛ انتقال الوثائق الأصلي السابق محفوظ.
- `prefers-reduced-motion` يعطل التحريك الجديد والتوهج وتتغير الحالات فورياً. الكشف عن تغير التفضيل يلغي Web Animations الجارية.
- `ScopeComposer`: عناصر checkbox/radio أصلية وتحديث موضوع رابط التواصل، دون حفظ البيانات أو إرسالها أو إنشاء سعر.
- البحث يعمل في الأدلة العامة الخمسة محلياً ويطابق بعض الاختلافات العربية مثل الهمزات والتشكيل وأداة التعريف. لا تخزين أو طلب API أو تحويل تتبع جديد.
