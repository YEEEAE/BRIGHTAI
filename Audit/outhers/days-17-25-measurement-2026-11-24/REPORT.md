## الزائر، النطاق، والأصل

| المسار | التصنيف والنتيجة |
|---|---|
| الوصول والأصول | **مثبت — HTTPS عام من نقطة فحص واحدة.** الرئيسية والتواصل والخدمات والأسعار والخصوصية والموارد والمنتجات والدلائل 200 على الأساسي والأصل. طلبات HTTP للرئيسية والتواصل أعادت 301 إلى HTTPS؛ HTTPS على www حوّل مرة واحدة إلى الأساسي محافظًا على المسار، وHTTP www استخدم تحويلين. 32 أصلًا مشارًا إليها من الرئيسية والتواصل والخدمات أعادت 200 من كل مضيف، منها 18 JavaScript و12 CSS وخطّان. الرئيسية والتواصل والخصوصية وعينة المسار والخرائط الحالية تطابقت بين الأساسي والأصل بالـSHA-256. تحقق شبكتين وحالة لوحة DNS/Render الحالية **غير متحققين**. |
| الفهرسة التقنية | **مثبت — GET للنطاق العام.** robots يشير لفهرس واحد. 64/64 رابطًا من الخريطة الحالية أعاد 200 مباشرة ووصفًا وعنوانًا وcanonical ذاتيًا وتعليمات تسمح بالفهرسة وloader القياس. محطة Firewall المفحوصة 200 وnoindex. `/sitemap.xml` ما زال 200 بـ264 رابطًا يتقاطع منها 13 مع الحالية ويزيد 251، ومنها `/demo/`. `/contact` و`/index.html` يعيدان 200 مع canonical إلى الوجهة المفضلة. ترتيب الظهور والفهرسة الفعلية **غير متحققين**. |
| صفحات الخطأ | **مثبت — العام والأصل.** المسار الاصطناعي المفقود أعاد 404. `/404/` و`/404.html` أعادا 200 مع noindex. **مثبت — Node محلي.** الخريطة القديمة والـaliases المختارة أعادت 301، ومسارات الخطأ الثلاثة أعادت 404؛ فرق النشر لا يزال مفتوحًا. |
| رحلة التواصل | **مثبت — HTML عام وChrome محلي.** الصفحة تعرض بريدًا وواتساب بروابط ثابتة بلا query أو fragment، ورابط الخصوصية، ومسودة اختيارية بلا نموذج HTML مرسل. اختبر Chrome نسخ نص اصطناعي وإشعار النسخ ونقرة البريد مع اعتراض الانتقال، ولم تظهر المسودة في dataLayer. فتح التطبيق الحقيقي واستلام الطلب ومدة الرد **غير متحققة**. |
| الهيرو | **مثبت — diff وبناء محلي.** لم تتغير ملفات الصفحة الرئيسية أو مكوناتها أو CSS. ملف HTML المبني للرئيسية مطابق بايتًا ببايت للّقطة المحلية السابقة (SHA-256 يبدأ `6118acfc`). |
