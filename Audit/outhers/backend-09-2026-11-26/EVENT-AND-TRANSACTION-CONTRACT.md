# Events, transactions and recovery boundaries — partial

The source uses PostgreSQL transactions, not a proven durable cross-process event bus. `src/server/kernel/db.mjs:67` is the transaction helper. Firewall records policy decision, product decision, Kernel audit, optional review and Ledger evidence through the same transaction (`src/server/firewall/service.mjs:245`–`:282`); actual evidence requirement depends on configured policy. Human Gate locks the request and grant, and writes the effect, consumed grant and evidence inside its transaction (`src/server/human-gate/service.mjs:321`–`:414`). Runtime DB role and target RLS remain unverified here.

Secure Chat reserves with a tenant advisory transaction lock before egress (`src/server/secure-chat/requests.mjs:32`–`:70`); it makes the provider call after that transaction, settles in a new transaction, and keeps an uncertain reservation charged (`src/server/secure-chat/service.mjs:246`–`:280`; `requests.mjs:104`–`:124`). There is no proof that all runtime stages are represented in Ledger. Do not automatically resend an unknown result.

Existing idempotency differs by operation. See `docs/API-CONTRACT.md` section منع التكرار. In particular Firewall request UUID blocks all duplicates, and its metadata fingerprint does not distinguish text with identical outcome. Secure Chat request UUID suppresses another send but does not provide the general payload-conflict contract. External Auth has no general HTTP retry guarantee. These gaps prevent API-04/ORC-04 acceptance.

Target event fields: eventId, eventType, schemaVersion, occurredAt, correlationId, causationId, authenticated actor/tenant, real asset/policy versions and sanitized metadata, with nullable relationships only when truly absent. Critical state and evidence linkage must commit atomically or enter explicit recoverable pending state. Evaluate a transactional outbox only for a demonstrated durable cross-boundary consumer; do not assert exactly-once delivery. For timeout/UNKNOWN, preserve reservation and perform authorized manual reconciliation before a new request. Never hold a DB transaction across external provider I/O.
