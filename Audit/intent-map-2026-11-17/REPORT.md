# خريطة نوايا البحث وقرارات المحتوى — BRIGHTAI

تاريخ التحليل: 2026-11-17. الحالة: DONE للتحليل والخطة؛ جميع القرارات توصيات، دون تعديل صفحات أو تحويلات أو نشر.

**القرار الأساسي:** تحسين الموجود؛ لا URL جديد. الاحتفاظ بروابط القطاعات المنشورة ذات الإشارة البحثية، وفصل أربع وظائف: مرجع عام، دليل تنفيذ، مادة متخصصة، وتقييم حل/نطاق دعم. لا تفرض بنية المصدر الأقصر على الصفحات المنشورة قبل استيعاب أدائها ومحتواها.

## النطاق والأدلة

- [الأدلة الـ32](guides-32.md): فهرس قابل للقراءة. جرى قراءة ملفات محتواها الحالية وحفظ snapshot وبصماتها في `evidence/guide-source-snapshot.json`؛ بيانات 20 دليلًا من `knowledge-guides.ts` و12 صفحة مستقلة.
- الإرث: تحليل نصوص 254/254 صفحة من لقطة محفوظة بتاريخ اليوم، تشمل hub/docs/solutions/blog/answer/kernel والصفحات الإنجليزية والهوية والثقة. تصنيف الصفوف الثانوية بمساعدة قواعد الموضوع والعنوان والنص؛ الثقة متوسطة، وليس اعتمادًا لتحويل جماعي. العناوين والHTTP الثانوية من اللقطة السابقة؛ ليست إعادة زحف حي كاملة في هذه المهمة.
- تحقّق حي جديد بـFirecrawl `maxAge:0` لخمس صفحات: hub العام، docs التنفيذ، حكومات، صحة، مصرفية الرياض؛ كلها HTTP 200، والمحتوى محفوظ في `evidence/live-0.json` إلى `live-4.json`. اختلاف المحتوى الحالي والإرث مثبت في هذه العينة.
- GSC موصول فعليًا؛ الخاصية المكتشفة والمستخدمة `sc-domain:brightai.live`، بحث web فقط، `final`، دون فلتر دولة أو جهاز. لا تصف الأرقام بأنها حجم الطلب السعودي؛ هي ظهور هذه الخاصية في كل الدول والأجهزة. الفترة 2026-10-18 إلى 2026-11-14، والمقارنة 2026-09-20 إلى 2026-10-17.
- 40 صف استعلام حالي و46 سابقًا؛ 116 صف صفحة حاليًا؛ `truncated:false` وفق الاستجابات، وليس ضمان اكتمال الاستعلامات التي تخفيها Google. إجمالي الخاصية 9 نقرات / 970 ظهورًا / CTR ‏0.93%. صفوف الاستعلامات لا تجمع إلى الإجمالي بسبب الإخفاء وطريقة التجميع. لا تجمع ظهور الصفحات للاستعلام لتقدير الطلب؛ قد تظهر صفحات متعددة في البحث نفسه.
- لم تُقَس روابط خلفية، أو تحويلات أعمال، أو search volume، أو أثر سببي للتنافس؛ لا توقعات نقرات أو ROI. لم تُجرَ مراجعة قانونية للادعاءات أو منافسين؛ ليستا شرطًا لحسم الخريطة الحالية.

## قرارات keep / update / merge

الجدول الكامل هو المرجع: **25 KEEP، 237 UPDATE، 49 MERGE مقترحة**. KEEP يعني حفظ URL والوظيفة، مع صيانة الحقائق؛ UPDATE تحسين الإجابة والحدود؛ MERGE نقل المفيد إلى عنوان موجود ثم تحويل واحد عند التنفيذ المصرح. كثرة UPDATE في الإرث سببها عدم امتلاك مصدره الحالي ومراجعة ادعاءاته، وليست دعوة لإعادة كتابة الجميع أولًا.

- لا تبدأ بدمج الرياض: لديها محتوى لجان ومشتريات وAML وخطة محلية، لكن عبارة «محتوى محلي» وحدها ليست إثبات قيمة مستقلة. اختبر استعلامات الرياض مقابل الاستعلام العام مدة لاحقة قبل القرار.
- الصفحات المحلية الأخرى مرشحة دمج في أصل القطاع لضعف التميّز المرصود؛ انقل أي متطلب تعاقدي/محلي مثبت، ولا تحولها جميعًا إلى solutions أو الصفحة الرئيسية.
- حافظ على الإنجليزية في `/answer/*` و`/en/*` للمراجعة اللغوية؛ لا 301 من الإنجليزية إلى العربية لمجرد تشابه الموضوع.
- لا تُستعمل مؤلفون أو عملاء أو فعاليات أو شهادات كدليل ثقة قبل إثباتها؛ التصنيف UPDATE لا يصادق عليها. لا تقوِّ صفحات الادعاءات آليًا لوجود نقرات.
- صفحة `manufacturing-ai-governance` تبقى صناعية متخصصة؛ إزالة الفقرات التي تستهدف الحكومة والاستشارات العامة، دون اختراع قطاع خامس في المصدر أو تحويل غير مكافئ.

## خطة التحرير

[الخطة المقروءة](editorial-plan.md) و[الخطة المرتبة CSV](editorial-plan.csv) تتضمن الأثر والثقة والجهد والمالك والاعتماد والمخرج ومعيار القبول. الدرجات أحكام تحريرية وليست قياسات Google: أثر 1–5، ثقة 0–1، جهد أيام عمل تحرير ومراجعة مقدرة؛ درجة الفرز = أثر × ثقة ÷ الجهد. تُنفذ شروط صون المصدر والادعاءات أولًا حتى لو كانت درجتها الحسابية أقل. ترتيب الفرص الخمس أعلاه مستقل عن ترتيب الاعتمادات التنفيذية.

1. احفظ مصدر الصفحات الفائزة وأوقف خطر إسقاطها عند نشر المصدر الحالي، وحدد سجل ملكية URL قبل التحرير. هذه بوابة تنفيذ لا تغيير نشر في هذه المهمة.
2. حرّر حكومات ثم صحة ثم أصل المصارف مع الاحتفاظ بالرياض؛ صحح الوعود غير المثبتة ووضّح سؤال النطاق وخطوة التواصل.
3. خصص docs للتنفيذ وhub للتعريف وservices لنطاق الاستفسار؛ انقل النصوص الفريدة قبل الدمج.
4. اربط الأدلة الداعمة من سياق السؤال: RACI والجرد والمخاطر → التنفيذ؛ أدلة القطاعات → صفحة القطاع؛ اختيار المنصة → products؛ نطاق الاستعانة → services. أضف روابط عكسية من الرئيسي إلى الأدلة المطلوبة، دون footer محشو.
5. بعد استقرار الوجهات، ادمج المداخل المكررة والمنتجات والأدلة؛ لا يبدأ تنظيف الذيل الطويل قبل الصفحات الخمس.

مهمتان متداخلتان لكن منفصلتان: تعديل محتوى «الاستشارات» لتعريف النطاق المسموح يمكن مراجعته الآن؛ اعتماد عرض استشارات تجاري أو وعد تسليم يحتاج قرار المالك. وكذلك مراجعة النص التنظيمي بواسطة مختص ومصدر رسمي قبل نشره؛ لا يعيد هذا التقرير تصحيحًا قانونيًا من عنده.

## شروط تنفيذ الدمج والتحقق اللاحق

كل MERGE قرار تحريري مشروط بالتنفيذ الصحيح، وليس أمر حذف. قبل أي 301: استرجاع مصدر الإرث، مقارنة كاملة للمحتوى والروابط وملفات التنزيل واللغات، قراءة GSC للصفحة والاستعلامات واستكشاف backlinks عند توفر المصدر. هذه المهمة لم تقِس backlinks؛ لذلك الثقة في أثر أي تحويل متوسطة. نقل الفريد، وتحديث الهدف ليجيب السؤال، ثم 301 مباشر بلا سلسلة إلى 200 canonical ذاتي مع تحديث الروابط والخريطة. لا target إلى صفحة MERGE أخرى؛ تحققت الخريطة من ذلك.

لا تسمح لخطة الـ57 صفحة المحلية بإسقاط الإرث الفائز عند النشر؛ متطلب حفظ/استيراد العناوين المنشورة مستقل عن إنشاء URL جديد. فحص `/hub/` وdocs وsolutions المنشورين لا يثبت وجود مصادرهم محليًا.

بعد تنفيذ ونشر مصرحين: سجل تاريخ التغيير وbaseline هذه الملفات؛ قارن بعد نافذتين نهائيتين متساويتين (28 يومًا، مع انتظار تأخر GSC) استعلام × صفحة لكل مجموعة، CTR والنقرات ومزيج الاستعلامات وحصة الوجهة المقصودة. افصل البلد والجهاز عند كفاية العينة. لا تطلب وصولًا عشوائيًا للموضع الأول أو نموًا بنسبة مختلقة. افحص كود التحويل وcanonical وrobots وفهرسة العناوين المهمة؛ غياب الاستعلام النادر لا يثبت فشل الصفحة. انخفاض النقرات أو ضياع استعلام متخصص يستدعي مراجعة النقل، لا إطلاق صفحات جديدة تلقائيًا.

## حدود التسليم

لا تعديل للمحتوى العام أو إعدادات Git أو حساب GSC، ولا commit/push/deploy. الخريطة تحليل محتوى وبيانات مباشرة مع لقطات محلية، وليست إثبات نشر أو جاهزية تشغيلية أو امتثال. بيانات الثقة التجارية والتحويلات غير مقاسة. التوصيات لا تعتمد أسعارًا أو SLA أو مدد تنفيذ. اختبارات بناء الموقع غير لازمة لأن التسليم ملفات تحليل فقط؛ تحقق الاتساق والتغطية في `evidence/validation.json`.

إعادة توليد الخريطة: من جذر المشروع `python3 audit/intent-map-2026-11-17/build-map.py` ثم `python3 audit/intent-map-2026-11-17/finish-map.py`؛ تستخدم الأدلة المحفوظة ولا تستعلم GSC أو تغيّر الصفحات. ملف `merge-decisions.csv` يعزل توصيات الدمج للمراجعة. `keyword_owner` يحدد صاحب الكلمة المقترح؛ `primary_page` مرجع المجموعة وقد يختلف عنه عند سؤال متخصص.
