3. افحص `git status` والكود الحالي ومكوّنات Astro المشتركة قبل التعديل. احفظ عمل المستخدم القائم وامتثل إلى صلاحيات Codex المحلية. **لا commit، لا push، لا PR، لا merge، لا تعديل عبر GitHub API، لا نشر، لا تغيير لبيئة إنتاجية.** العمل على ملفات النسخة المحلية فقط.
4. **ممنوع تغيير الصفحة الرئيسية `/` أو هيروها أو Constellation أو Header أو Footer أو BaseLayout أو CSS العام إذا نتج عنه تغيير الرئيسية؛** افصل التنسيق والحركة في مكونات/ملفات scoped تخص الصفحات المطلوبة. لا تعِد بناء النظام البصري من الصفر، ولا تمسح نصوصًا أو أقسامًا سابقة دون سبب موثق وتعليمات صريحة.
5. الهوية: عربية سعودية RTL، خلفية سوداء `#000000`، نص أبيض، بنفسجي `#8052FF`، زعفراني `#FFB829`، أخضر `#15846E` في موضعه، وخط الموقع الحالي وشعاره من `src/data/brand.ts`. لا تستخدم شعارات مزيفة أو صور عملاء أو شهادات أو أسعارًا أو مدد احتفاظ مخترعة.
6. **النطاق صفحات وتجارب أمامية Frontend، لا تنفيذ Backend أو APIs تشغيلية.** أي رسوم/قرارات/أحداث داخل الصفحة تكون تعليمية ببيانات اصطناعية، وعليها وسم ظاهر «توضيحي — لا يتصل بخدمة فعلية». لا ترسل مدخلات المستخدم لنموذج أو إلى خادم. لا تعرض نجاح إجراء فعلي أو تخزين سجل أو موافقة أمنية دون تنفيذ مثبت.

## بنية الصفحة التفصيلية — نفّذ الأقسام جميعًا

1. Hero «الخطر ما يحدده اسم النموذج. يحدده استخدامه.» مع الحالة «P1 / مخطط».
2. ابدأ بالسياق: الغرض، مالك الاستخدام، أطراف متأثرة، فئات البيانات، نموذج/مزود ومكان معالجة محتمل؛ أمثلة افتراضية.
3. عرض سجل أصل AI: بطاقة كيان تعليمي مع owner وpurpose وmodel_version وpolicy_version؛ لا تربط بقاعدة بيانات.
4. **مصفوفة تعليميّة قابلة للاختيار:** الاحتمال × الأثر، مع شرح أن التقسيمات والأرقام المعروضة أمثلة وليست منهج تقييم مصادقًا عليه.
5. «لماذا خرج هذا التقييم؟»: لوحة تفسير للعوامل والافتراضات والثقة والبيانات الناقصة والضوابط؛ تغيّر بحسب الحالة المختارة.
6. المخاطر قبل وبعد الضوابط: توضيح الفرق بين intrinsic/residual risk ومسؤول اعتماد الخطر المتبقي، مع امتناع عن إعلان انخفاض رقمي مخترع.
7. منهج التقييم الهجين (قواعد/تحليل) كتصور، مع guardrails والتحيز وعدم اليقين.
8. مسار review/appeal/approval: من يطلب مراجعة ومن يقرّها، دون أن تكون الموافقة داخل UI موافقة حقيقية.
9. **تغير مادي:** نموذج أو مصدر بيانات أو وجهة أو غرض مختلف يؤدي إلى احتياج إعادة تقييم؛ محاكي مقارنة قبل/بعد.
10. خيارات النشر والتكاملات الاختيارية مع Firewall/Human Gate/Ledger، وعدم تسويق التقييم على أنه إنفاذ مستقل على حركة غير متكاملة.
11. نطاق 48 ساعة المخطط، والأسئلة الشائعة وأدلة القبول المطلوبة وCTA صادق.
