## السبب والإصلاح
حالة `open` في HTML ثم إغلاق JavaScript وفق عرض الشاشة أحدثت تغيرًا كبيرًا بعد أول رسم. تكرر ذلك في التنقل العام وتصنيفات docs وفهرس الأدلة. بدأت الإفصاحات مغلقة في HTML؛ سكربتات viewport الحالية تفتحها لسطح المكتب، وsummary يظل متاحًا دون JavaScript. لم تتغير الخطوط أو لوحة الهوية أو الشعار أو رسم الكوكبة. تغيّر hover زر الرئيسية إلى درجة بنفسجية معتمدة موجودة لتحسين التباين، وأصبحت حركة SVG في PDPL تتوقف عند تغيير تفضيل المستخدم.

## فحص الأصول والحركة والسكربتات
- TTF: ثلاثة أوزان 200/400/600، نحو 657 KiB مجتمعة عند تحميلها جميعًا؛ font-display:swap وpreload للوزن 400. رصدت shifts صغيرة بعد تحميل الخط (مثل العنوان/النص/controls). لم يُغيّر التنسيق إلى WOFF2 أو تُلغ أوزان بلا تجربة منفصلة تثبت المكسب وتحفظ العربية.
- عنصر LCP على الجوال في الرئيسية هو h1؛ في docs قبل الإصلاح كان شعارًا داخل القائمة المفتوحة، ثم أصبح عنوان المحتوى بعد إتاحة رؤيته مبكرًا. تغير المرشح موثق؛ ليس تسريع تنزيل صورة بالضرورة. PDPL وISO: فقرات مرئية، والمنتج: شعار، والتواصل: h1 (راجع lcp في كل تشغيل للمرشح النهائي).
- الكوكبة: بيانات محلية 100000 byte، رسم Canvas/فرز نقاط دوري مع IntersectionObserver ووقف عند document.hidden وتقليل الحركة؛ trace أثبت FunctionCall يصل إلى 96ms في تشغيل قبل الإصلاح. لا يفسر ذلك انزياح القوائم؛ بقي الرسم والهوية دون تغيير.
- GA4: بقي gtag الخارجي فعّالًا. traces أثبتت EvaluateScript حتى 300ms وFunctionCall حتى 290ms في خط الأساس على CPU×4. تتباين تكلفته بين التشغيلات؛ لا يُنسب اختلاف العمل الحاجب إلى CSS أو الخط وحده. لم نغيّر التتبع أو إعداداته ضمن هذه المهمة.
- لا تعني تسمية المصدر مجموع تكلفة حصريًا: FunctionCall قد يكون متداخلًا مع EvaluateScript، لذلك لا تجمع الشرائح لتقدير TBT. القائمة التفصيلية محفوظة في comparison.json مع max/count.

## إصلاحات الوصول المثبتة
- الرئيسية: main يقبل التركيز البرمجي لرابط التخطي؛ hover/focus للزر يستخدم --color-action-hover-strong مع filter:none. أبيض/‏#9166ff كان 3.78:1 قبل زيادة brightness؛ أصبح أبيض/‏#6f43e6 =5.80:1 للكتابة 14px/600. فحص MGD Contrast Checker مع computed style في Chrome؛ لا تغيير للوحة المعتمدة.
- PDPL: role=group للرسم الذي يحتوي نقاطًا تفاعلية، بدل role=img؛ مزامنة pauseAnimations/unpauseAnimations مع change لتفضيل تقليل الحركة وتنظيف listener عند pagehide.
- ISO: underline لروابط الفقرات والقوائم حتى لا يعتمد تمييزها على اللون وحده.
- المختبر: div بدل aside للشريط الداخلي ذي التنقل المسمى، لتجنب landmark تكميلي داخل main. العرض نفسه.
