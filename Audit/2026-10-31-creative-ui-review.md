## التشخيص والاتجاه

- كانت صفحات المنتجات الخمسة تكرر عنواناً ووصفاً وقائمة أسئلة، بلا تمثيل يوضح وظيفة كل منتج. القطاعات والأركان تستخدم التكوين نفسه تقريباً.
- مركز المعرفة اعتمد شبكة بطاقات متساوية، والمقالات افتقدت فهرساً يساعد على التنقل. كثرة الفراغ في بعض الأقسام لم تقابلها معلومات بصرية مفيدة.
- الرئيسية اعتمدت مشهد جزيئات يتطلب Canvas وبيانات مشتقة من مرجع خارجي؛ أصبح الرسم الجديد خريطة أصلية لعلاقات المنتجات، دون حذف ملفات المشهد القديم.
- قورنت ثلاثة اتجاهات: مشهد جزيئات غامر، لوحة مؤشرات، ومسارات قرار تعليمية. اختير الأخير لأنه يشرح الحوكمة دون اختلاق أرقام أو إيهام المستخدم باتصال بمنتج.
- الشعار والألوان الأساسية والخط المحلي وRTL ووسم GA4 بقيت معتمدة. بناءً على توجيه المالك أثناء المهمة، أُعيد `Header.astro` مطابقاً لـHEAD، وعُزل عن وزن النص وحركة روابط المحتوى الجديدة. لا تغيير مقصود في هيدر الرئيسية.

## نظام التصميم والحركة

المكونات الجديدة: `SystemMap.astro`, `ProductIcon.astro`, `ProductExperience.astro`, `MotionController.astro`. الملفات المشتركة: `experience.css`, `BaseLayout.astro`, `PageShell.astro` وطبقة experience المضافة إلى `tokens.json`.

- IBM Plex Sans Arabic المحلي باقٍ؛ وزن محتوى 400، أسطر مريحة، وعزل أسماء المنتجات بـbdi. هيدر الرئيسية يحتفظ بوزنه الأصلي.
- خلفية سوداء، أسطح تقنية داكنة وتوهج محدود، أزرار بنفسجية وحواف أدق، كهرماني للتوضيح. مصفوفة المخاطر تضيف ألواناً دلالية مع تسميات نصية فلا يعتمد معناها على اللون فقط.
- الحركة: 120ms لاستجابة الحالة، 220ms للانتقالات الصغيرة، 480ms لدخول العنوان والأقسام مرة واحدة. easing مشترك `.2,.7,.2,1`. موثقة أيضاً في tokens.json.
- العنوان ظاهر من HTML الأولي ويتحرك 10px فقط دون إخفائه. لا تقسيم لحروف العربية. يظهر كل المحتوى بدون JavaScript.
- مسارات SVG تُرسم عند hover أو focus-within؛ الأيقونات والأسهم تستجيب للتفاعل. ظهور الأقسام عبر IntersectionObserver، مع إيقاف المراقبة عند pagehide.
- انتقال صفحات أصلي cross-document عبر CSS `@view-transition` عند دعم المتصفح؛ تنقل عادي عند غياب الدعم. لم يُضف Astro ClientRouter، لذلك يعاد تهيئة السكربتات لكل وثيقة ولا توجد دورة swap جديدة تتطلب إعادة ربط listeners.
- `prefers-reduced-motion` يلغي الحركات والتحولات، مع إبقاء تغيير الحالة والمحتوى. لا Canvas أو WebGL أو فيديو جديد أو حركة دائمة.

## قياسات الأداء الفعلية

الأحجام gzip من مخرجات build بنفس البيئة قبل وبعد؛ CSS هو مجموع ملفات CSS الناتجة للموقع، وليس قياس نقل شبكة مضغوطة من خادم إنتاج.

| القياس | قبل | بعد |
| --- | ---: | ---: |
| HTML الرئيسية | 111134 بايت | 23811 بايت |
| HTML الرئيسية gzip | 16180 بايت | 5803 بايت |
| CSS الموقع gzip | 4214 بايت | 8564 بايت |
| ملف بيانات الجزيئات المطلوب بالرئيسية | 100000 بايت | غير مطلوب |

السكربتات صغيرة ومضمّنة في HTML بواسطة Astro؛ عدم وجود ملفات JS خارجية لا يعني عدم وجود JavaScript. الخطوط المحلية لم تتغير، وتظل أكبر جزء من التحميل: نحو 672KB لثلاثة أوزان.

Chrome DevTools عند عرض 1200px، عينة غير مخنوقة: LCP قبل **244ms** وCLS **0.00247**؛ بعد **144ms** وCLS **0**. هذه مقارنة محلية بعينة واحدة وليست إثبات تحسن مستقر أو Core Web Vitals للإنتاج.

Playwright على النسخة النهائية، دون محاكاة 4G أو جهاز بطيء، مع حجب طلب GA4 في الاختبار: عند 360px LCP **156ms** وCLS **0.000064**؛ عند 1440px LCP **56ms** وCLS **0.000293**. مجموع موارد الموقع المسجلة نحو 801KB، إضافة إلى HTML؛ لا يشمل نقل خدمة التحليلات المحجوبة. **INP لم يُقَس**. لا ادعاء تحقيق ميزانية الأداء على أجهزة فعلية أو إنتاج.
