# حدود on-prem / air-gap — BLOCKED

لا يمكن ادعاء on-prem أو air-gap استنادًا إلى Blueprint أو إلى استخدام Groq.

## المعوّقات

1. استضافة Render مُدارة بخدمة واحدة `brightai-site`؛ لا مُثبّت محلي.
2. Neon Postgres وNeon Auth خارجيان؛ `/readyz/` يتصل بـJWKS عند تفعيل الفحص.
3. Groq مزود خارجي بمفتاح وميزانية؛ أي استخدام يعني خروج بيانات.
4. لا Dockerfile/Compose/Helm، ولا مزود نموذج محلي، ولا حزمة منع egress.
5. لا SBOM موقّع ولا أرشيف موقّع.

## متطلبات تغيير الحالة

- مزود محلي أو تعطيل مؤكد للذكاء الاصطناعي مع فحص عدم اتصال.
- منع egress مع دليل DNS/HTTP، وتعطيل فحص JWKS البعيد أو استبداله محليًا.
- Postgres وobject store وJWKS محليون بملكية المشتري.
- حزمة offline بالتجزئات والتوقيع + استعادة معزولة بنتيجة مستقلة.
- قرار مالك مكتوب بتصنيف البيانات.
