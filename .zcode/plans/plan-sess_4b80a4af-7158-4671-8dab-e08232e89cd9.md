   - KPI queries (all parameterized, no `SELECT *`):
     - Tests Today / This Week (`lab_test_records` by `created_at` vs `date('now','localtime')` — match dashboard.ts's existing date convention), Draft (status DRAFT), Awaiting Review (SUBMITTED + UNDER_REVIEW), Approved (APPROVED), PASS/FAIL/HOLD (counts of `final_result` on non-VOID records), Equipment Requiring Attention (derived from `status_raw` mapping + calibration derived state per D-1), Calibration Due (derived at read time from `lab_equipment_calibration` dates — NOT a stored enum), Documents Due for Review (`lab_documents.review_due_date` vs today), Retests Open (`lab_test_retests.status='OPEN'`), Data Quality Issues (read-only derived checks per page-reference §56: tests missing lot/equipment/tester/final-result, incomplete samples, equipment missing code/serial/location/calibration, document issues — counts only, informational, never mutates).
