## بروتوكول التنفيذ (إلزامي لكل برومبت)

بعد كل برومبت شغّل التحقق وافشل بصوت عالٍ لو أي خطوة صفرت:

```bash
npm run build            # ≥ 125 صفحة، 0 أخطاء
npm run verify:all       # exit 0
npm run performance:budget   # لو المس بـ CSS/JS
```

- لا `console.log` في الإنتاج. لا `var`. لا classes Tailwind. لا `<iconify-icon>`.
- استخدم `<svg><use href="/icons.svg#mdi-*"></use></svg>`.
- احترم `prefers-reduced-motion: reduce` في كل حركة.
- استخدم خصائص CSS منطقية (`inline-start/end`) — لا `left/right` إلا للجزر المقصودة.
- كل صفحة تورث `KernelLayout` ولا تكرّر الشِل. كل رسم SVG للشعارات (لا PNG).
- الجزر التقنية (هاش، Trace ID، IBAN، كود) داخل `dir="ltr" unicode-bidi: isolate`.
- بعد الإنشاء: حدّث `src/data/kernel.ts` (الوحدات + navigation + cross-links) و
  `public/sitemap.xml` (عبر `npm run sitemap:generate`).
- لا تضيف اعتماديات JS جديدة (GSAP/Three/Spline ممنوعة).

4. لوحة الأوامر ⌘K: مودال مركزي 640px، حقل بحث، نتائج مجمّعة (صفحات · سياسات · سيناريوهات · تقارير · أوامر). تنقّل أسهم، Enter تنفيذ، Esc خروج. أوامر سريعة: شغّل سيناريو · افتح Trace · ولّد تقرير · بدّل الوضع.
5. مدخل الدور: DPO · CISO · مدير امتثال · مطوّر. يعيد ترتيب الوحدات والمؤشرات ويُحفظ (localStorage).
6. نظام العرض التوضيحي: مبدّل "بيانات تجريبية / بياناتي" + شارة خصوصية دائمة (لا تخزين، لا تدريب، الجلسة تُمسح).
7. الحالات المشتركة (أضِف atoms لو ناقصة): فارغ (أيقونة + عنوان + شرح + زر فعل، ممنوع نص "لا توجد بيانات" وحده) · تحميل (skeleton نبض 1.4s يطابق المحتوى) · خطأ (بطاقة حمراء + سبب + إعادة محاولة + أبلغ) · نجاح (توست أسفل اليسار 3ث + زر تراجع).

- التحقق: npm run verify:all = exit 0، npm run performance:budget = exit 0.
