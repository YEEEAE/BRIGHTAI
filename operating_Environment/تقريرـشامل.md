# تقرير شامل: BRIGHTAI Kernel - منصة حوكمة الذكاء الاصطناعي

## 1. ماهية المنتج (حرفياً)

**BRIGHTAI Kernel** هو منصة تشغيلية سعودية لحوكمة الذكاء الاصطناعي داخل المنشآت. يعمل كـ **AI Gateway + Firewall + Audit Layer** بين موظفي الشركة ونماذج الذكاء الاصطناعي الخارجية (Groq, Gemini, OpenAI, etc).

### الفكرة الأساسية:
بدلاً من أن يرسل الموظف طلبه مباشرة إلى ChatGPT أو Claude، يمر الطلب عبر Kernel الذي:
1. **يفحص PII** (البيانات الشخصية) ويحجبها
2. **يقيّم المخاطر** (0-100)
3. **يطبق السياسات** (قواعد الشركة)
4. **يسجل كل شيء** في سجل تدقيق غير قابل للتعديل
5. **يطلب موافقة بشرية** للقرارات عالية المخاطر
6. **يولد أدلة PDF** جاهزة للجهات الرقابية (NCA, SDAIA, SAMA, SFDA)

### **2.3 `/kernel/chat/` - المحادثة الآمنة**
**الوظيفة:** واجهة دردشة AI بضوابط حوكمة كاملة.

**المحتوى:**
- **3-Pane Layout:**
  - **Threads Panel:** قائمة المحادثات السابقة
  - **Chat Thread:** المحادثة الحالية
  - **Context Panel:** السياسات المطبقة، Trace ID، الأدلة

**الـ AI هنا:**
```typescript
// كل رسالة ترسل إلى:
POST /api/ai/chat {
  message: "رسالة المستخدم",
  sessionId: "uuid-v4", // للحفاظ على السياق
  promptId: "compliance" | "policies" | "evidence" | "audit" | "scenarios"
}
```

**Pipeline لكل رسالة:**
1. **Firewall Check:** الكشف عن PII (هوية، جوال، IBAN، إلخ)
   - إذا وُجد PII حرج → **Block** (HTTP 451)
   - إذا وُجد PII متوسط → **Require Approval** (HTTP 428)
   - إذا كان آمن → **Allow** + Redact
2. **Quota Check:** فحص الحصة (30 طلب/دقيقة، حد يومي)
3. **Provider Call:** استدعاء Groq (llama-3.3-70b) أو Gemini (2.5-flash)
4. **Session Persistence:** حفظ المحادثة في Redis (TTL 10 دقائق)
5. **Trace Generation:** إنشاء Trace ID فريد لكل رسالة

**Features:**
- **Multi-turn Context:** يحتفظ بآخر 10 رسائل في Redis
- **Streaming:** SSE (Server-Sent Events) للردود الحية
- **Circuit Breaker:** إذا فشل Groq، يتحول إلى Gemini تلقائياً
- **Firewall Banner:** تنبيه إذا تم حجب PII

## 3. استخدام AI (Groq & Gemini) - التفاصيل التقنية

### **3.1 الـ API Endpoint**
```
POST /api/ai/chat
```

### **3.2 Request Shape**
```typescript
{
  message: string,           // النص (4000 حرف max)
  sessionId?: string,        // UUID v4/v7 للمحادثات متعددة الأدوار
  promptId?: string,         // "compliance" | "policies" | "evidence" | "audit" | "scenarios"
  provider?: "groq" | "gemini" | "auto"  // افتراضي: "auto"
}
```

### **3.3 Response Shape**
```typescript
// Non-streaming (Accept: application/json)
{
  reply: string,
  blocked?: boolean,
  decision?: "block" | "require_approval" | "allow",
  traceId?: string,
  findings?: Array<{ type, action, confidence, start, end }>,
  provider?: "groq" | "gemini",
  sessionId?: string
}

// Streaming (Accept: text/event-stream)
event: token
data: {"delta":"..."}

event: done
data: {"provider":"groq","sessionId":"uuid"}
```

### **3.4 Provider Configuration**
```typescript
// Groq (Primary)
{
  model: "llama-3.3-70b-versatile",
  endpoint: "https://api.groq.com/openai/v1/chat/completions",
  max_tokens: 800,
  temperature: 0.4
}

// Gemini (Fallback)
{
  model: "gemini-2.5-flash",
  endpoint: "https://generativelanguage.googleapis.com/v1beta/models/gemini-2.5-flash:generateContent",
  maxOutputTokens: 800,
  temperature: 0.4
}
```

### **3.5 AI Firewall (K3)**
قبل استدعاء الـ Provider، يمر الطلب عبر Firewall:
```typescript
const K3_POLICY = {
  blockOnCritical: true,
  actions: {
    SAUDI_ID: 'block',           // هوية وطنية → Block
    IQAMA: 'block',              // إقامة → Block
    SAUDI_IBAN: 'block',         // آيبان → Block
    CARD_OR_ACCOUNT: 'block',    // بطاقة/حساب → Block
    CREDENTIAL: 'block',         // بيانات دخول → Block
    PATIENT_ID: 'block',         // ملف مريض → Block
    SAUDI_PHONE: 'require_approval',  // جوال → Require Approval
    EMAIL: 'require_approval',   // بريد → Require Approval
  }
};
```

### **3.6 Session Persistence**
```typescript
// Redis-backed conversation context
{
  sessionId: "uuid-v4",
  maxMessages: 10,
  ttlSeconds: 600  // 10 دقائق
```

### **3.7 Quota & Rate Limiting**

### **4.1 المستخدم الجديد (First-Time User)**

**الخطوة 1: الهبوط على `/kernel/`**

- يقرأ "رحلة Kernel - 5 مراحل"

**الخطوة 3: رؤية الـ Pipeline**
