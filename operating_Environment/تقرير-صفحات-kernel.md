# تقرير الحالة النهائية — `src/pages/kernel`


## الطبقة المشتركة (Kernel Shell)

كل صفحة من الـ16 تجلس داخل شِل واحد. هذي العناصر موجودة في كل مكان، فلا تتكرر في وصف الصفحات:

**شريط جانبي ثابت** بثلاث مجموعات: *التشغيل* · *الرقابة* · *الإثبات*. تنقل بدون إعادة تحميل، وحالة كل وحدة تظهر كنقطة ملونة.

**شريط علوي صادق**: `Mode: Demo` · `Inference: <المزوّد الفعلي>` · `DB` · `Latency` · زر **بحث Trace ID**. اللافتة تعرض المزوّد الحقيقي، والادعاء القديم انتهى.

**درج الرحلة (Trace Drawer)**: أي Trace ID في أي صفحة قابل للنقر، يفتح خط زمني بالـ6 مراحل + سلسلة الهاش + روابط لكل وحدة لمست هذا الطلب.

**لوحة الأوامر (⌘K)**: تنقل، تشغيل سيناريو، فتح سياسة، توليد تقرير. كل شيء بالكيبورد.

**مدخل الدور**: DPO · CISO · مدير امتثال · مطوّر. يعيد ترتيب الوحدات والمؤشرات، ويُحفظ.

**نظام العرض التوضيحي**: مبدّل *بيانات تجريبية / بياناتي*، وشارة خصوصية دائمة: لا تخزين، لا تدريب، الجلسة تُمسح.

# الصفحات الست عشرة

## 🟢 مجموعة التشغيل

### 1. `/kernel/` — الفهرس
**الدور:** بوابة القصة، لا شبكة روابط.

يفتح على **زر "شغّل حادثة"** الذي يشغّل جولة سردية 90 ثانية عبر 7 مشاهد (كتابة الطلب → اشتعال الـFirewall → صعود المخاطر لـ87 → مطابقة السياسة → حقن قيد السجل → هبوط الطلب في الموافقات → توليد ملف الدليل)، مع أربعة سيناريوهات بديلة (PII · حقن أوامر · تصدير طبي · SA-IBAN)، وشريط تقدم قابل للإيقاف والتخطي.

تحته: KPIs حية، شريط الامتثال الستة، وشبكة الوحدات مرتّبة حسب دورك.

**الإضافة العالمية:** **عدّاد "ما مُنع اليوم"** حي (سجلات PII محجوبة · ريالات مخاطرة متفاداة تقديرياً) + **زر "ابدأ بنصك أنت"** ينقلك للـPlayground محمّلاً مسبقاً.

### 2. `/kernel/playground/` ⭐ — الملعب
**الدور:** نواة المنتج مكشوفة للعامة. هذي الصفحة التي تُحكم على المنتج بها.

**ثلاثة أعمدة:**

**اليمين (الإدخال):** منطقة نص كبيرة + 6 عيّنات جاهزة بنقرة (هوية · IBAN · سجل طبي · رواتب · حقن أوامر · طلب بريء) + مبدّلات السياق (القسم، الدور، الحساسية، سحابي/محلي) + مفاتيح تشغيل/إطفاء لكل سياسة من الـ11.

**الوسط (خط الأنابيب الحي):** ست بطاقات تشتعل بالتسلسل مع زمنها الفعلي:
1. **الاستلام** — Trace جديد، توكنز، لغة
2. **فحص PII** — نصك مُعاد عرضه مع **تظليل ملوّن فوق كل كيان** (هوية برتقالي · جوال أزرق · IBAN أحمر · بريد رمادي · طبي بنفسجي) وجدول ثقة لكل كشف
3. **تقييم المخاطر** — عدّاد يصعد مع **تفكيك الـ12 عاملاً**، كل عامل بشريط ومساهمته بالنقاط
4. **مطابقة السياسات** — أي سياسة اشتعلت ولماذا، برابط للسياسة
5. **استدعاء النموذج** — يعرض **النص بعد التعمية** (ما يراه النموذج فعلاً) والإجابة بثّاً
6. **توليد الدليل** — بطاقة EVD + فتح الملف

بين كل مرحلتين قرار مرئي: ✅ مرّ · ⚠️ عُمّي · ⛔ حُظر · ⏸️ ينتظر.

**اليسار (النتيجة):** الحكم بلغة بشرية + **تبويب "بدون Kernel"** يعرض ما كان سيصل للنموذج لو لا حوكمة + خريطة المواد المتأثرة + أزرار (افتح الرحلة · حمّل الدليل · أضفه كسيناريو · شارك).

**الإضافات التي ترفعه لمصاف الأفضل عالمياً:**

| الميزة | لماذا تفرق |
|---|---|
| **وضع الفرق (Diff) A/B** | نفس النص بإعدادين جنب بعض، والفروق مظللة حرفياً |
| **بذرة الحتمية (Seed)** | نفس المدخل ينتج نفس النتيجة دائماً، قابل للاستشهاد به في تدقيق |
| **آلة الزمن المصغّرة** | مؤشر سحب على المراحل الست، ترجع وتقدّم داخل التنفيذ |
| **"لماذا؟" على كل قرار** | نقرة على أي حكم تفتح شرحاً بالعوامل والأوزان، لا صندوقاً أسود |
| **صدّر كود** | يحوّل جلستك إلى `curl` / Python / TS جاهزة للصق |
| **رابط دائم قابل للمشاركة** | يشفّر الإعدادات لا النص، عشان النقاش الجماعي |
| **عدّاد التكلفة والزمن** | تكلفة الطلب بالهللة وزمنه بالمللي، لحظياً |
| **وضع احتياطي محلي** | لو سقط المزوّد، المراحل 1-4 تعمل كاملة (وهي التي تبيع) بشارة صريحة |
| **ويدجت قابل للتضمين** | `<iframe>` يحط الملعب في أي موقع أو عرض تقديمي |
| **كتاب الوصفات** | 20 حالة استخدام جاهزة بنقرة، مصنّفة بالقطاع |
| **أول تشغيل تعليمي** | جولة 3 خطوات لا تتكرر، مع تخطي دائم |
| **حدود مهذبة** | سقف طلبات وطول واضح مسبقاً، برسالة بديلة لا فشل صامت |
| **جوال حقيقي** | الأعمدة تنقلب أكورديون، وخط الأنابيب يصير شريطاً أفقياً بالسحب |
| **وصولية كاملة** | كل مرحلة تُعلن لقارئ الشاشة، وتظليل PII له بديل نصي، وتنقل كيبورد تام |

### 3. `/kernel/chat/` — المحادثة المحكومة
**الدور:** الاستخدام اليومي، لا الاستعراض.

بانر Firewall الحي، تبويبات (الرسائل/السياق/التنبيه)، اختصارات (C · Enter · Shift+Enter · Esc)، ومثال الحظر الكامل (2,400 عميل → 1,847 سجل PII → 87% → blocked).

**الجديد:** كل Trace قابل للنقر · زر **"افتح هذي الرسالة في الملعب"** · **شريط حوكمة مصغّر تحت كل رسالة** (PII: 0 · مخاطر: 8 · مسموح) · عرض النص بعد التعمية بنقرة · **اقتراح إصلاح**: "طلبك محظور، جرّب هذي الصياغة" مع نسخة معدّلة تمر.

---

### 4. `/kernel/scenarios/` — مختبر السيناريوهات
**الدور:** الاختبار قبل الإنتاج.

الـ12 سيناريو المعروض (هوية وطنية · عقود حكومية · تصدير طبي · حقن أوامر · رواتب · SA-IBAN · أسرار في الكود · بحث مجهول الهوية · تلخيص NDA · سير ذاتية · تقرير بنكي · حقن SQL) صارت **قابلة للتشغيل الفعلي داخل محرك الملعب**، لا بطاقات وصفية.

**الجديد:** تشغيل دفعي لـ100 سيناريو مع شريط تقدم · **مصفوفة نتائج** (سيناريو × نموذج) بألوان · مقارنة بالتشغيل السابق (تحسّن/تراجع) · تحويل أي نتيجة فاشلة إلى **سياسة مقترحة بنقرة** · تصدير تقرير الجاهزية.

---

### 5. `/kernel/redteam/` 🆕 — ساحة الفريق الأحمر
**الدور:** ادعُ الناس لكسر منتجك أمام الجميع. أجرأ صفحة في المنتج، وأقواها تسويقياً.

مربع واحد: **"حاول تخترق Kernel"**. تكتب هجومك (حقن أوامر، تجاوز ضوابط، استخراج أسرار، تحايل على تعمية PII)، والنظام يحكم: صُدّ أم نفذ.

**تتضمن:** لوحة صدارة أسبوعية للمخترقين · مكتبة 40 تقنية هجوم معروفة قابلة للتجربة · **عرض الدفاع الذي أوقفك** (شفافية كاملة) · إذا نجح هجومك: بلاغ تلقائي + شارة + السياسة المقترحة للسد · تصنيف الهجمات حسب OWASP LLM Top 10 · وضع "هجوم متسلسل" متعدد الرسائل.

**لماذا تنجح:** لا أحد يصدّق ادعاء الأمان. الجميع يصدّق ما كسره بيده وفشل.

### 9. `/kernel/replay/` 🆕 — آلة الزمن
**الدور:** يجيب على أخطر سؤال في الحوكمة: *"لو كانت سياستنا الجديدة مفعّلة الشهر الماضي، وش كان بيتغير؟"*

تختار فترة + مجموعة سياسات مقترحة → النظام يعيد تشغيلها على الطلبات التاريخية ويعرض: كم طلب كان سيُحظر إضافياً، كم كان سيُسمح، كم إيجابية كاذبة، وأي الأقسام تتأثر أكثر.

**تتضمن:** مقارنة "قبل/بعد" جنب بعض · **تحذير الأثر الجانبي** (هذي السياسة كانت ستحظر 340 طلباً مشروعاً) · إعادة بناء أي حادثة خطوة بخطوة للتحقيق · تصدير النتيجة كمذكرة قرار للإدارة.

## 🟣 مجموعة البنية

### 14. `/kernel/models/` 🆕 — سجل النماذج والموجّه
**الدور:** يثبت حياد المنصة ويحوّل اختيار النموذج من تخمين إلى قرار بالأرقام.

جدول لكل نموذج متصل: الزمن · التكلفة/ألف توكن · معدل نجاح السيناريوهات · معدل الهلوسة · مكان البيانات (سحابي/محلي/سعودي).

**تتضمن:** **حلبة مقارنة** — نفس الطلب على 3 نماذج جنب بعض بالنتيجة والزمن والتكلفة · **قواعد التوجيه الذكي** (بيانات حساسة → نموذج محلي، أسئلة عامة → سحابي) قابلة للضبط بصرياً · تجاوز يدوي · تنبيه عند تدهور أداء نموذج · لوحة صدارة أمان النماذج محدّثة أسبوعياً.

### 15. `/kernel/connectors/` — الموصلات
الثمانية بحالتها الحية: SAP ✅ · Oracle EBS ✅ · Dynamics ✅ · Epic ✅ · SharePoint ✅ · Okta ✅ · Moodle ⏸️ معلق · **Salesforce ❌ توكن منتهٍ**. كلها read-only بـOAuth/SAML.

**الجديد:** التنبيه صار **قابلاً للتنفيذ** (زر تجديد التوكن) · مخطط تدفق يوضح أين تمر البيانات · **اختبار موصل حي** يرسل استعلاماً تجريبياً ويعرض الاستجابة · طابور الانتظار مرئي أثناء الانقطاع · دليل بناء موصل مخصص.

الإبقاء على حالة الفشل معروضة عمداً يظل أذكى قرار تصميمي في المنتج كله.

### 16. `/kernel/api/` 🆕 — وحدة المطوّر (تشمل الوثائق)
**الدور:** تحوّل الزائر التقني من معجب إلى مستخدم في عشر دقائق. وهي أيضاً بديل `/kernel/docs/` المكسور سابقاً.

**تتضمن:** مرجع API كامل بأمثلة حية قابلة للتنفيذ من الصفحة · مفتاح تجريبي فوري بلا تسجيل (محدود) · SDK لثلاث لغات مع نسخ بنقرة · **فاحص Webhook** يعرض الحمولة الواردة لحظياً · دفتر أخطاء بالمعاني والحلول · دليل الترحيل "من استدعاء مباشر إلى Kernel في 3 أسطر" · حالة الخدمة وسجل الإصدارات · وثائق التشغيل للفرق غير التقنية في تبويب منفصل.
