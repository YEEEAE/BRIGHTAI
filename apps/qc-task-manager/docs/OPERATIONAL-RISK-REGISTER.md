## Risk treatment rules

| Conclusion type | Treatment |
|---|---|
| Controlled company requirement | Record exact source title, revision, section/page, owner, and effective state before encoding. |
| Current application rule | Verify against current source and named test; do not describe it as compliance. |
| Engineering recommendation | Create a decision record and impact assessment; implementation requires owner approval where behaviour changes. |
| Source required | Keep the gap visible, preserve current source data, and do not invent fields, limits, pages, or approval meaning. |

## Priority closure sequence

1. Obtain controlled sources and owners, starting with laboratory FAIL/HOLD/retest, document control/WI, and records retention.
2. Resolve the known acceptance P0-1/P0-2 under the closure contract before using full E2E-dependent coverage as evidence.
3. Decide whether the application-only rules (five-year awareness, calibration windows, retest eligibility, and closure gates) are accepted company policy or must change.
4. Only then create targeted tests for verified application rules and update domain status with fresh evidence.
