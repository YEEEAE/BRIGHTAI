# QC UI Visual 007 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Upgrade every QC Task Manager visual route to a readable, consistent, responsive enterprise presentation while leaving product behaviour unchanged.

**Architecture:** Improve shared semantic surfaces, type roles, tables, controls, and page shell first, then apply the existing canonical primitives to route families where their page-level markup still bypasses them. A deterministic route-audit guard owns coverage; the evidence document records the result for every visual route and explicitly excludes APIs.

**Tech Stack:** Astro SSR, Tailwind CSS 3, React 19 islands, existing Node test scripts.

**Spec:** `apps/qc-task-manager/docs/superpowers/specs/2026-09-02-qc-ui-visual-007-design.md`

## Global Constraints

- Keep `SystemBackground` unchanged: no scrim, video replacement, resize, or global visual effect.
- Do not alter data queries, forms, API contracts, URLs, RBAC, audit behaviour, or workflow states.
- Reuse active v2 tokens and existing UI primitives; do not add dependencies.
- Keep English UI, native table semantics, text-visible statuses, visible focus, and 44px standalone touch targets.
- Verify 320, 360, 375, 390, 430, 768, 1024, 1280, 1440, and 1920px; report failures as failures.
- Do not commit, push, or deploy.
