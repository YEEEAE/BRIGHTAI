# React و Next.js في RTL

استخدم هذا المرجع عند العمل على مكوّنات React أو صفحات Next.js أو layouts أو app router، عندما تكون المشكلة في مكان ضبط الاتجاه أو في طريقة تمريره داخل الشجرة.

## مبدأ عام

ضع `dir="rtl"` و`lang="ar-SA"` في أقرب مستوى منطقي يعبّر عن تجربة عربية كاملة. لا تمرر `dir` يدوياً عبر طبقات كثيرة إذا كان layout أو الصفحة نفسها هي المكان الطبيعي لضبطه.

## أين تضع الاتجاه

### React SPA

- إذا كانت الواجهة كلها عربية، ضع الاتجاه على الجذر الأعلى المناسب مثل root layout أو app shell.
- إذا كانت شاشة بعينها عربية داخل تطبيق متعدد اللغات، ضع الاتجاه على مستوى الصفحة أو الحاوية الرئيسية لتلك الشاشة.

### Next.js App Router

- فضّل ضبط `lang` و`dir` في `app/layout.tsx` إذا كانت التجربة عربية على مستوى الموقع.
- إذا كان المشروع متعدد اللغات، اجعل layout المرتبط بالعربية أو segment العربي هو المسؤول عن ذلك.
- لا تنشئ provider جديداً فقط لتمرير قيمة `rtl` ما لم يكن المشروع يعتمد فعلاً على هذا النمط.

### Next.js Pages Router

- إذا كانت المشكلة عامة، راجع `_document`, `_app`, أو layout المشترك أولاً.
- إذا كانت المشكلة محصورة، عدّل الصفحة أو المكوّن المحلي بدلاً من تعديل البنية العامة بلا داع.

## أنماط مفضلة

- أصلح الاتجاه من layout أو الصفحة عندما يكون الخلل عاماً.
- أصلح spacing أو alignment داخل المكوّن عندما تكون المشكلة محلية.
- استخدم class names أو tokens الموجودة بدلاً من خلق API جديدة لتمرير اتجاه الواجهة.

## أنماط غير مفضلة

- إضافة prop مثل `isRTL` إلى عدد كبير من المكوّنات فقط لعلاج مشكلة كان يمكن حلها في CSS أو container واحد.
- إنشاء hook أو context جديد ما لم يكن المشروع يعتمد بالفعل على تبديل اتجاه حي بين لغات متعددة.
- إعادة بناء مكوّن كامل لأن أيقونة أو spacing أو alignment كان يمكن إصلاحها موضعياً.

## نقاط مراجعة React

- هل ترتيب عناصر JSX يعتمد ضمناً على LTR؟
- هل `flex-row` أو `justify-between` أو `gap` تعمل كما هو متوقع مع النص العربي؟
- هل الأيقونات المضافة عبر components تحتاج قلباً دلالياً أو إعادة موضع فقط؟
- هل أي inline styles تستخدم `left/right` أو `marginLeft/marginRight`؟

## نقاط مراجعة Next.js

- هل metadata أو الـ root HTML يعرّفان `lang="ar-SA"` فعلاً؟
- هل الصفحة العربية ترث الاتجاه من layout الصحيح؟
- هل هناك مزيج بين server components وclient components يخفي موضع المشكلة؟
- هل التصميم على الجوال ينهار بسبب layout مشترك غير مهيأ لـ RTL؟

## مثال قرار سريع

- المشكلة عامة في الموقع العربي كله: ابدأ من layout.
- المشكلة في صفحة واحدة: ابدأ من الصفحة.
- المشكلة في عنصر واحد: ابدأ من المكوّن وCSS المرتبط به.
- المشكلة في نص مختلط أو أرقام: راجع مرجع `mixed-content-bidi.md`.
