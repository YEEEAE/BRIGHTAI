## 3. تفصيل التفاعلات و حالات الواجهة

### 3.1 مراحل الدليل (الواجهة الموجودة)

| الحدث | السلوك | المعلومة التي تظهر | بديل دون JavaScript |
|---|---|---|---|
| فتح «التقاط الحد الأدنى» | كشف وصف المصدر والقرار والنسخة | «لا تحفظ نصوصًا حساسة افتراضيًا» | `<details>` HTML يعمل بحد ذاته |
| فتح «سلامة الدليل» | كشف مفهوم Hash/توقيع | «مخطط، غير محسوب» | نصوص ثابتة كاملة |
| فتح «الحفظ» | شرح Retention/Legal Hold | «مدد الاحتفاظ يحددها العقد» | قائمة نصية |
| فتح «التصدير» | شرح Independent Verification | «ليس ملفًا حقيقيًا تم تنزيله» | تعليمات مرئية |

### 3.2 مثال «سليم/معدل»

- الحالتان `DEMO_INTACT` و`DEMO_MODIFIED`: تتغير الأيقونة والوصف والمخطط، دون إجراء فحص تشفيري أو ادعاء رسالة VALID صادرة عن فاحص.
- تظهر شارة ثابتة **«مثال تعليمي فقط — لا تُخزّن أحداث فعلية»** داخل بطاقة المثال.
- إذا تعذر JavaScript، تعرض حالتي المثال شرحًا نصيًا قابلًا للقراءة؛ لا يُخفى المحتوى قبل تهيئة حركة ناجحة.
- مع `prefers-reduced-motion` تظهر النتيجة مباشرة دون scrambling أو نبض مستمر.
- الرسائل الحية (`aria-live`) تعلن حالة المثال النهائية فقط. الوصول بالكيبورد مع `focus-visible` و`aria-pressed` عند اللزوم.

### 3.3 تجربة فحص حقيقة مستقبلية — بوابة منفصلة

لا يُفتح زر «تحقق الآن» على الصفحة العامة حتى يتوفر API فعلي وبيئة مستقلة وآلية واضحة تمنع إدخال أدلة العملاء في الموقع العام. إن قُدمت Sandbox لاحقًا، تكون ببيانات اصطناعية حصريًا، وتميز نتائج `VALID / INVALID / INDETERMINATE / UNTRUSTED_SOURCE / KEY_UNAVAILABLE` دون تبسيط مخل.

### 3.4 حالات النموذج التجاري

| الحالة | ما يراه الزائر | الإجراء |
|---|---|---|
| `NOT_READY` الحالية | «التجربة غير مفعلة؛ يمكنك إرسال استفسار» | رابط contact عام |

- 360 / 768 / 1440px مرجع لفحص مستقبلي، وليس نتائج تحققت لهذا المستند.

## 9. معايير قبول صفحة المنتج

1. كل نص يوحي بإثبات تشغيلي يتطلب دليلًا حقيقيًا أو يُعاد لصيغة «مستهدف/توضيحي».
2. لا يوجد زر تجربة مفعلة أو حالة إدخال بيانات حقيقية قبل اعتماد البنية والخصوصية.
3. واجهة المقارنة والـtimeline مفهومة على الجوال ومع تعطيل JavaScript وتقليل الحركة.
4. لا تعديل للرئيسية أو الهيدر أو أي أصل محمي.
5. تتطابق أسماء الميزات مع `FEATURE-STATUS.yaml` والمتطلبات الرسمية، دون تحويل Demo إلى دليل هندسي.
