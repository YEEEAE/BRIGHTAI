وثائق Human Approval Layer

طبقة الموافقة البشرية تضيف Human-in-the-Loop للقرارات الحساسة بناءً على المخاطر والسياسات.

الإجابة المختصرة

Human Approval Layer توقف القرار أو الطلب عالي المخاطر وترسله لصاحب الصلاحية، ثم تسجل الموافقة أو الرفض داخل Audit Trail.

متى يتم التصعيد؟

  • عند وجود بيانات حساسة.
  • عند ارتفاع Risk Score.
  • عند ارتباط القرار بتأثير مالي أو وظيفي أو صحي.
  • عند مخالفة السياسة أو عدم وضوح الغرض.

مكونات سير العمل

  1. تحديد عتبة المخاطر.
  2. تحديد أصحاب الموافقة حسب القسم.
  3. إرسال الطلب للمراجعة.
  4. توثيق القرار والوقت والسبب.
  5. إعادة الطلب لمسار التنفيذ أو الرفض.
