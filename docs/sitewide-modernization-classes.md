# Sitewide Modernization Classes

هذه الكلاسات مشتركة لتقليل inline styles بدون تغيير هوية الصفحات أو أسماء الكلاسات القائمة.

| Class | Purpose |
| --- | --- |
| `.bright-perf-section` | بديل مشترك لـ`content-visibility: auto` مع `contain-intrinsic-size` لتحسين الأداء تدريجياً. |
| `.bright-text-strong` | بديل دلالي للتكرار `font-weight: bold`. |
| `.bright-muted-cell` | نص خلية/صف بلون داكن متوسط مع padding موحد. |
| `.bright-muted-cell-soft` | نص خلية/صف بلون muted أفتح للخلفيات الداكنة. |
| `.bright-demo-note` | نص ملاحظات demo بسطرية مريحة. |
| `.bright-demo-title` | عنوان صغير داخل بطاقات demo. |
| `.bright-demo-copy` | نص وصفي داخل بطاقات demo. |
| `.bright-demo-support-title` | عنوان دعم داخل demo smart hiring. |
| `.bright-demo-panel` | سطح بطاقة demo خفيف مشترك. |
| `.bright-demo-pill-link` | رابط CTA صغير داخل بطاقات demo. |
| `.bright-demo-success-panel` | تمييز بطاقة إيجابية داخل demo بدون inline style. |

مبدأ الاستخدام: أضف الكلاس الجديد بجانب الكلاسات الحالية ولا تستبدل أسماء الكلاسات الموجودة إلا إذا صار فيه سبب وظيفي واضح.
