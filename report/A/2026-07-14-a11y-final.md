## 6. المخاوف المتبقية (مقبولة)

### 6.1 3 large-only contrast cells
`--interactive-hover` كـ text على bg-surface/elevated/4 (4.42/4.11/3.68). **مقبول** لأن:
- الاستخدام الشائع للـ hover هو BACKGROUND للأزرار (نص معاكس = 4.68 ✅)
- WCAG 2.2 SC 1.4.3 يسمح بـ 3:1 للنصوص الكبيرة (≥18pt)
- hover states brief (تظهر مع الماوس، تختفي بسرعة)

### 6.2 25 touch targets < 44px
- **الحلّ العملي**: أغلبها inline text links داخل paragraphs (exempt per WCAG 2.5.8 Inline Text Link Exception)
- **Chip الـ 32px**: أكبر hit area بدون كسر الـ visual chip design
- **Kernel logo 41×44**: brand asset ثابت، off by 3px width (لا يستاهل تعديل)

### 6.3 brand Teal shift (15% brighter)
- `--interactive-primary`: `#2a8a7e` → `#20a597`
- button text contrast: 4.62 → 6.32 (AAA)
- DEC-SovB-001 (Sovereign Calm) محفوظ: نفس الـ hue، أفتح فقط
- brand-50 → brand-900 scale **لم يتغيّر** (visual identity intact)

## 7. الـ Rollback

كل دفعة في commit منفصل. الـ rollback آمن:

```bash
# Rollback batch 3
git revert <batch-3-sha>
npm run build && npm run verify:all

# أو rollback كل شي
git revert <batch-1-sha>..<batch-3-sha>
npm run build && npm run verify:all
```

**النقطة الذهبية**: الـ 3 commits atomic. لو دفعة وحدة سببت regression، نرجعها لحالها.
