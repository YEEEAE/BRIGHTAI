# KRN-M29 — QA شامل لصفحات الكيرنل (Responsive + WCAG 2.2 AA) + إصلاح بطاقات الموصلات

**التاريخ**: 2026-08-02
**الوكيل**: BrightAI Workspace Agent
**المهمة**: فحص شامل لصفحات /kernel/* — إزالة overflow أفقي على 5 viewports، مسح WCAG 2.2 AA بـaxe وإصلاح المخالفات، وكتابة تقرير نهائي.
**الوضع**: Senior

## الملخص التنفيذي

M29 خلصت بكل بواباتها: **axe 0 مخالفات** على كل الـ21 صفحة kernel (كانت 3 critical + 22 serious)، والـ responsive **0 failing** (16 صفحة × 5 viewports = 80 حالة)، والبناء `npm run build` ناجح exit 0، و`npm run verify:all` ناجح exit 0 بعد تنظيف ملفين مكررين.

اكتشفنا أثناء الشغل خلل M26 حقيقي: صفحة `/kernel/connectors/` — قسم الموصلات كامل (KPIs + البطاقات + الدرج + التوست) كان **بدون أي CSS**. `connectors.css` كان legacy ميت يطابق الـHTML القديم (`.connectors-hero*`)، بينما الصفحة الحالية تستخدم نظام `kc-*` كامل لم يُكتب له CSS إطلاقاً. كتبنا نظام `kc-*` كامل (~380 سطر) في `kernel/assets/css/pages/connectors.css`، وحذفنا الـlegacy الميت.

كمان اكتشفنا إن الفوتر التسويقي من `BaseLayout` يظهر أسفل صفحات kernel **بدون أنماطه** (لأن `components.css` غير محمّل في الكيرنل) — سبب مخالفة target-size الوحيدة المتبقية. أخفيناه في `kernel.css` لأن للكيرنل فوتره الخاص في السايدبار.

## ملخص إصلاحات axe (سابقاً C:3 S:22 → الآن C:0 S:0)

- **3 critical** أُصلحت:
  - audit: الخلايا أخذت `role="cell"` (كانت بلا role داخل `role="row"`).
  - playground: `pg-mini-timeline` role=list→group؛ tablist فُصل عن الـtabpanels وأخذوا `aria-labelledby`.
  - policies: tbody `role="rowgroup"` + الصفوف `role="row"` + الخلايا `role="cell"`.
- **serious** أُصلحت: `nested-interactive` (connectors — الأزرار خرجت من منطقة النقر)، `scrollable-region-focusable` ×2 (`#code-output`, `.km-table-wrap`)، و22 مخالفة `color-contrast` (رفع ألوان متعددة إلى `--text-secondary`/قيم AA، وإزالة `opacity` من `<small>` داخل فهرس السياسات).
- **target-size** (20× `footer__social-link`): حُل بإخفاء الفوتر التسويقي غير المصمم على صفحات kernel (كان 1176×18؛ الآن يختفي وظهر فوتر السايدبار).

## قرارات

- **DEC**: كتابة نظام `kc-*` كامل بدل إصلاح الـlegacy — الـlegacy `.connectors-*` ميت (0 استخدام في الصفحة الحالية، فقط في `src/data/migrated-pages/kernel-connectors.json` الأرشيفي).
- **DEC**: إخفاء الفوتر التسويقي على kernel عبر `kernel.css` فقط (`body.kernel-shell footer.footer { display: none }`) — بدل تحميل `components.css` في الكيرنل (أثقل). لو المستخدم يبي الفوتر التسويقي على صفحات kernel مصفّف، الحل: تحميل components.css هناك.
- **DEC**: حذف ملفي " 2" المكررين فقط (بموافقة المستخدم) — الـ4 ملفات kernel-api الأخرى ميتة أيضاً لكن تُركت (تنظيف مستقبلي).

## المخاطر المتبقية

- فوتر السايدبار (`kernel-sidebar__footer`) له روابط هدفها صغير (كانت خارج نطاق M29 — نُقلت لـ known-issues).

## اقتراحات للمتابعة
