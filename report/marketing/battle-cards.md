# BrightAI — Sales Enablement: Battle Cards + Objection Handling

**الإصدار**: 1.0

## 1) Battle Card: IBM watsonx.governance

| البند | IBM watsonx.governance | BrightAI |
|---|---|---|
| السوق | عالمي، تركيز enterprise غربي | سعودي ١٠٠٪، امتثال PDPL/NCA محلي |
| اللغة | إنجليزي أساساً | عربي + إنجليزي، دعم فني سعودي |
| البيانات | سحابة دولية غالباً | استضافة محلية ١٠٠٪ (سيادة بيانات) |
| السعر | مرتفع، enterprise | مرن يناسب السوق السعودي |
| السرعة | تكامل أطول |middleware غير مرئي، لا عرقلة إنتاجية |

**متى نربح**: قطاع حكومي/صحي/مصرفي سعودي يبي سيادة بيانات + امتثال محلي + دعم بالعربي.
**متى نخسر**: شركة متعددة الجنسيات تبي معيار عالمي موحّد مع IBM موجود أصلاً.

**ضربة قاضية**: "هل IBM تضمن استضافة بياناتك داخل السعودية وتدعمك بلجنة امتثال PDPL بالعربي؟"

## 2) Battle Card: Palo Alto Prisma (AI Security)

| البند | Prisma AISec | BrightAI |
|---|---|---|
| التركيز | أمن شبكات + حماية نماذج من هجمات | حوكمة + امتثال + أدلة تشغيلية |
| العميل | فرق أمن تقليدي | امتثال + أمن + تحول رقمي |
| الإخراج | تنبيهات أمنية | سجل تدقيق + ملف أدلة للجهات التنظيمية |

**متى نربح**: العميل يبي يثبت الامتثال لجهة تنظيمية (PDPL/NCA)، مو بس حماية تقنية.
**متى نخسر**: العميل يبي فقط حماية من هجمات model poisoning.

**ضربة قاضية**: "Prisma يحمي الشبكة، بس هل يطلع لك ملف أدلة جاهز للتدقيق عند سdaia؟"

## 3) Discovery Call Template (١٥ دقيقة)

1. **افتتاح (٢ د)**: شكر + هدف اللقاء (نفهم احتياجك ونحدد الخطوة الجاية).
2. **فهم النطاق (٥ د)**:
   - وين تستخدمون AI اليوم؟
   - وش نوع البيانات اللي تدخل/تخرج؟
   - مين يتخذ القرار بعد المخرج؟
3. **الألم (٤ د)**: غياب السجل؟ تسرب بيانات؟ صعوبة تتبع موافقات؟
4. **القيمة (٢ د)**: ربط حالة العميل بحل مناسب (Firewall / Audit / Approval).
5. **الخطوة الجاية (٢ د)**: تقييم جاهزية أو ديمو مخصص + اتفاق على مخرج قابل للقياس.

## 4) Demo Script (عربي، ٢٠ دقيقة)

- **٠-٣ د**: المشكلة — "الذكاء الاصطناعي ينتشر، بس مين يراقبه؟"

- **١٧-٢٠ د**: الخطوة الجاية — تقييم جاهزية.

## 5) Objection Handling

**"غالي"**
> نقارن الوفر: تكلفة حادث امتثال واحد (غرامة + ضرر سمعة) أعلى بكثير من الاشتراك السنوي. استخدم [حاسبة ROI].

**"when نحتاج وقت طويل للتكامل"**
> نشتغل كـ middleware غير مرئي، ما نعطّل إنتاجيتكم. التقييم يبدأ بأيام.

**"عندنا سياسة بالفعل"**
> ممتاز — إحنا ما نستبدل سياستك، نحوّلها لضوابط وأدلة تشغيلية قابلة للقياس.

**"نخاف على بياناتنا"**
> استضافة محلية ١٠٠٪، السيادة لكم، ولا تخرج البيانات حدود المملكة.

**"ننتظر توجيه من الجهة التنظيمية"**
> نحوّل المتطلبات المعتمدة إلى ضوابط وأدلة اليوم، عشان تكونون جاهزين لما يصدر التوجيه.
