# ورقة عمل قابلة للتحرير | شكوى واحدة

**نموذج تدريبي.** املأ نسخة لكل حالة مصطنعة. اكتب في سجل القرار أنواع المعلومات المحذوفة بأسماء عامة ودون قيمها.

## 1. قالب تنقيح الشكوى

| الحقل | يعبّئه موظف الصياغة |
| --- | --- |
| معرّف الحالة التدريبي | |
| طلب العميل بكلماته المختصرة | |
| الحقائق اللازمة ومصدرها داخل التمرين | |
| المعلومات الناقصة ومن يستطيع تأكيدها | |
| أنواع البيانات المحذوفة أو المستبدلة | |
| الملخص المنقح في جملتين | |

إرشاد التنقيح: احذف الاسم والجوال والعنوان ومعرّفات الشحنة والطلب وأي إحالات لمرفقات غير لازمة. راجع اجتماع التفاصيل التي قد تكشف الشخص حتى بعد حذف الاسم. استخدم معرّف التمرين عند الحاجة للربط بين الأوراق.

## 2. قالب صياغة الرد

> أهلًا، نعتذر عن [أثر مؤكد]. فهمنا أنك تطلب [الطلب]. [ما نعرفه عن الحالة]. [الخطوة المسموح بها ومن يتابعها]. سنوافيك بتحديث [الموعد المصرح به] عبر [القناة المعتمدة].

| الحقل | يعبّئه موظف الصياغة |
| --- | --- |
| نص الرد للمراجعة | |
| رقم النسخة | |
| الإجراء الداخلي المقترح | |
| التفصيل الذي يحتاج اعتماد المشرف قبل الالتزام | |

عند غياب موعد مصرح به، اطلب تحديد موعد تحديث من المشرف قبل اعتماد النسخة. اكتب إجراء المتابعة الداخلي في خانته، واستخدم في الرد ما يحتاج العميل معرفته من ذلك الإجراء.

## 3. قائمة مراجعة المشرف

ضع علامة على ما تحقق، وسجّل الدليل أو سبب الإيقاف في السجل.

- [ ] يقتصر الملخص والرد والسجل على المعلومات اللازمة والمصطنعة.
- [ ] حالة الشحنة وسبب أي إجراء مسنودان ببطاقة الحالة وأحدث تحديث متاح.
- [ ] يعترف الرد بالتأخير ويبين طلب العميل والخطوة التالية بلغة واضحة ومحترمة.
- [ ] توقيت التحديث والقناة ضمن القواعد المصطنعة، والرد خالٍ من ضمان الإلغاء أو الاسترجاع قبل تحقق شرطه.
- [ ] للطلب المعلّق مالك متابعة وموعد وشرط إعادة فتح، أو سبب تصعيد واضح.
- [ ] القرار يحدد نسخة الرد والدور المخول، ويميز اعتماد الرد عن قرار الإجراء التشغيلي.

عند نقص شرط أو صلاحية، أعد المسودة للتعديل إن أمكن إصلاحها، أو صعّدها لصاحب الصلاحية. يبقى الرد التدريبي موقوفًا إلى أن يبت المشرف في النسخة الجديدة. يمكن اعتماد رد تحديث آمن مع إبقاء طلب الإلغاء أو الاسترجاع معلّقًا.
