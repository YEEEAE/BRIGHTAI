## 1. السيو التقني وهندسة المعمارية (Technical SEO & Architecture)

### التشخيص الحالي
الموقع يحتوي على محتوى عربي غني ومنظم (خاصة في صفحات `/try/data-quality/` و `/try/text-analysis/`)، لكنه يعاني من:
- هيكلة مجلدات مسطحة نسبياً مع تكرار في شريط التنقل داخل `/try/`
- غياب `canonical` tags واضحة
- Core Web Vitals بحاجة إلى تحسين سريع لمستخدمي الجوال (78%+ من الزيارات في السعودية)

### الإجراءات التنفيذية الفورية

**أ. إعادة هيكلة Silo Structure (خلال 14 يوماً)**

```
/ (الرئيسية)
├── /solutions/
│   ├── ai-agents/
│   ├── automation/
│   ├── contract-ai/          ← أولوية قصوى
│   ├── aiaas/
│   └── data-analysis/
├── /sectors/
│   ├── government-tenders/
│   ├── healthcare/
│   └── education/
├── /try/                     ← يبقى كـ Playground مع noindex
└── /faq/
```

**ب. تحسين Core Web Vitals للجوال السعودي**

- أضف `loading="lazy"` + `fetchpriority="high"` للصورة الرئيسية (LCP)
- حوّل جميع الصور إلى **WebP** مع fallback
- أزل أي JavaScript غير ضروري من صفحات الـ Demo

**مثال كود `<head>` محسّن (الصفحة الرئيسية):**
```html
<link rel="canonical" href="https://brightai.site/" />
<meta name="robots" content="index, follow, max-image-preview:large" />
<meta name="viewport" content="width=device-width, initial-scale=1.0" />
```

- أنشئ صفحة مركزية `/faq/` تحتوي على **15 سؤالاً** بصيغة "ما هي..." و"كيف يساعد...".

## 5. الكيانات والبيانات المنظمة المتقدمة (Advanced Schema Markup)

أضف هذه الـ JSON-LD في `<head>` لكل صفحة رئيسية:

### 1. Organization + LocalBusiness (الصفحة الرئيسية)
```json
{
  "@context": "https://schema.org",
  "@type": ["Organization", "LocalBusiness"],
  "name": "Bright AI",
  "legalName": "شركة برايت للذكاء الاصطناعي",
  "url": "https://brightai.site",
  "logo": "https://brightai.site/logo.png",
  "address": {
    "@type": "PostalAddress",
    "addressLocality": "الرياض",
    "addressCountry": "SA"
  },
  "areaServed": ["المملكة العربية السعودية"],
  "sameAs": [
    "https://linkedin.com/company/brightai-sa",
    "https://x.com/brightai_sa"
  ]
}
```

### 2. SoftwareApplication (صفحة Data Quality)
```json
{
  "@context": "https://schema.org",

  }

```
