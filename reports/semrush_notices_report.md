## المطلوب

لكل صفحة من الصفحات المذكورة:

1. **ابحث عن الروابط الفارغة**: افتح ملف HTML وابحث عن:
   - `<a href="..."></a>` (رابط فارغ تماماً)
   - `<a href="..."><img src="..." /></a>` (صورة بدون alt)
   - `<a href="..."><div></div></a>` (div فارغ داخل الرابط)
   - `<a href="..."> </a>` (مسافة فقط)

2. **أضف نص وصفي مناسب**: لكل رابط فارغ:
   - إذا كان يحتوي على صورة → أضف alt text وصفي بالإضافة لنص مرئي
   - إذا كان أيقونة/سهم → أضف aria-label أو نص sr-only
   - إذا كان فارغ تماماً → أضف نص يصف الصفحة المرتبطة

3. **نص الـ Anchor يجب أن يكون**:
   - وصفياً ومرتبطاً بالصفحة المستهدفة
   - يحتوي على كلمات مفتاحية مناسبة (بدون حشو)
   - بالعربية للصفحات العربية وبالإنجليزية للصفحات الإنجليزية

## Prompt #4 — تفعيل HSTS (Issue 205)

```
أنت مهندس أمان ويب و DevOps خبير. موقع brightai.site لا يدعم HSTS (HTTP Strict Transport Security) وأحتاج تفعيله.

## المشكلة
الخادم لا يرسل هيدر Strict-Transport-Security في استجاباته HTTP، مما يعني:
- المستخدم قد يصل للموقع عبر HTTP قبل إعادة التوجيه
- عرضة لهجمات Man-in-the-Middle
- عرضة لهجمات SSL Stripping
- عدم دعم HSTS يُنقص من نتيجة الأمان في أدوات SEO

## الموقع مستضاف على: Netlify (أو Render)

## المطلوب:

### الخطوة 1: إضافة هيدر HSTS
أضف الهيدر التالي في ملف _headers:

```
/*
  Strict-Transport-Security: max-age=31536000; includeSubDomains; preload
```

### الخطوة 2: التحقق من المتطلبات المسبقة
قبل تفعيل HSTS تأكد من:
1. ✅ جميع صفحات الموقع تعمل عبر HTTPS بشكل صحيح
2. ✅ جميع الموارد (CSS, JS, Images) تُحمّل عبر HTTPS
3. ✅ لا يوجد Mixed Content (موارد HTTP في صفحة HTTPS)
4. ✅ إعادة التوجيه من HTTP → HTTPS تعمل على مستوى الخادم
5. ✅ جميع Subdomains تدعم HTTPS (إذا استخدمت includeSubDomains)

### الخطوة 3: قيم HSTS الموصى بها
- `max-age=31536000` — سنة كاملة (الحد المطلوب للـ preload)
- `includeSubDomains` — يشمل جميع النطاقات الفرعية
- `preload` — يسمح بإضافة الموقع لقائمة HSTS Preload في المتصفحات

### الخطوة 4: التدريجي (إذا أول مرة)
إذا أول مرة تفعّل HSTS، ابدأ بقيمة منخفضة:
1. الأسبوع الأول: max-age=300 (5 دقائق) — للاختبار
2. الأسبوع الثاني: max-age=86400 (يوم)
3. بعد التأكد: max-age=31536000 (سنة)

### الخطوة 5: التقديم لـ HSTS Preload
بعد التأكد من عمل كل شيء:
- سجّل الموقع في https://hstspreload.org/
- هذا يجعل المتصفحات تعرف مسبقاً أن الموقع HTTPS فقط

## أخرج:
1. ملف _headers المعدّل
2. أي تعديلات أخرى مطلوبة
3. خطوات التحقق بعد التفعيل
```
