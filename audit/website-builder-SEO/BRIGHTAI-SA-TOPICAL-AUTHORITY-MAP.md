## 3) عمق السلطة (Authority Depth) — فجوات «ماذا/كيف»

| السؤال | الحالة |
|---|---|
| ما هي حوكمة AI؟ | ✅ مغطاة |
| لماذا/متى إلزامية؟ | ✅ عبر PDPL/NCA/SDAIA clusters |
| من يحتاجها؟ | ✅ قطاعات |
| كيف تُنفّذ؟ | ✅ أدلة تنفيذ |
| ما المخاطر/الضوابط؟ | ✅ |
| ماذا تقول الجهات السعودية؟ | ✅ واسع — يحتاج تنظيم pillar |
| ما الأدلة المطلوبة؟ | ⚠️ جزئي — يقوى بأصل evidence/checklist موحد |
| كم التكلفة؟ | ✅ |
| كيف يقيَّم المورد؟ | ⚠️ معايير اختيار شفافة موثقة ناقصة |
| حوكمة وكلاء AI (Agents) | ❌ فجوة موضوعية كاملة |
