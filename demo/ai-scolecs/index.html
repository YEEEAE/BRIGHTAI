أسئلة خاصة بالمختبر

هل يعطي الطالب الإجابة مباشرة؟

وضع الطالب مبني على أسلوب سقراطي، فيسأل أسئلة قائدة ويزيد التلميح تدريجياً بدل تسليم الحل فوراً.

هل يدعم التصحيح من صورة؟

نعم عبر وكيل خلفي يدعم الملفات، مع إرجاع ملاحظات بنمط تصحيح واضح يحتاج اعتماد المعلم.

هل تعرض الإدارة أسماء الطلاب؟

التقرير الإداري يعرض مؤشرات مجمعة، ويمكن للنسخة المؤسسية فرض إخفاء الهوية افتراضياً.

هل يمكن ربطه بمنصة تعلم؟

نعم عبر API أو Webhook بعد تحديد الصلاحيات وخريطة الحقول وسجل التدقيق.

هل المحتوى مناسب ثقافياً؟

تعليمات النظام تفرض أمثلة متوافقة مع القيم السعودية، مع سياقات إسلامية مناسبة عند الحاجة.

ما حدود الديمو؟

الديمو يستخدم بيانات اصطناعية ومخرجات استرشادية؛ القرارات التعليمية الرسمية تحتاج مراجعة بشرية.
