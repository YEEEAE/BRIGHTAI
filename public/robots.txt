# Intentional policy (2026-09-03):
# - Traditional search crawlers: allow.
# - AI search / grounding / citation crawlers: allow only where provider
#   documentation confirms that role.
# - Model-training-only crawlers: disallow by default.
# - /api/ is not crawlable. Every Allow group repeats Disallow: /api/
#   because a named User-agent group does not inherit * rules.
# - /go/ holds internal redirect hubs (e.g. /go/whatsapp/ → wa.me).
#   SEMRUSH-UNBLOCK (2026-09-08): user decision — /go/ is ALLOWED again.
#   The hub page is index, follow + sitemap-included and carries no direct
#   wa.me href in its HTML (client-side redirect), so audit crawlers can
#   fetch it safely without misreporting its destination as a broken link.
# - Cloudflare Managed robots.txt must stay OFF. When ON it prepends its own
#   training Disallow + Content Signals block before this file, creating
#   duplicate/conflicting directives for the same tokens.
# - No Content-Signal directive here on purpose (validators flag it).
# - Single canonical Sitemap below. No Host directive.
