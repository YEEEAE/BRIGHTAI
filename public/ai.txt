# ============================================
# Google-Extended Policy (explicit semantics)
# ============================================
# Google-Extended governs Google's Gemini API and Bard training use ONLY.
# It does NOT control Google Search indexing.
# Google Search indexing is governed separately by Googlebot.
# Allowing Google-Extended therefore signals consent to Gemini/Bard training
# use of brightai.site content; allowing Googlebot keeps search results intact.
# If you ever want to opt out of Gemini training while keeping search indexing,
# change the Google-Extended rule to Disallow: / and leave Googlebot on Allow.

# Applebot-Extended Policy (explicit semantics)
# ============================================
# Applebot-Extended governs Apple Intelligence training use.
# It does NOT control Apple Spotlight / Siri Web results (Applebot).
# Same split semantics as Googlebot vs Google-Extended.
